# 竞赛信息接入

目前监测六个赛事来源：

| 来源 | 自动读取方式 |
| --- | --- |
| 中国数学会全国大学生数学竞赛栏目 | 发现举办通知，读取官方 PDF |
| 中国计算机学会 CCSP 通知栏目 | 发现报名通知，读取官方正文 |
| 蓝桥杯软件、电子与鸿蒙个人赛 | 读取官网当前报名范围及条件 |
| 蓝桥杯视觉艺术设计赛 | 读取官方赛事页面、年级资格及日程 |
| 全国大学生英语竞赛官方合作报名页 | 读取报名范围及专业分类，后续以页面更新为准 |
| 全国大学生电子商务三创赛 | 读取当前届次的报名流程和日程 |

数学、CCSP 按栏目发现新通知；其余读取当前赛事页面，并不宣称覆盖整个赛事官网的全部文章。英语赛使用组委会提供的赛氪合作报名页，不是接通赛氪全站竞赛聚合。

入口为 `scripts/collect-competitions.mjs`，发布数据为 `public/data/competitions.json`。已有本机同步任务每小时检查，文档缓存一小时；需要电脑开机联网。原文、PDF 与缓存在忽略目录 `.sites-runtime/collectors/competitions/`，不会放到公网。PDF 使用本机已有 Python/pypdf，动态页面使用已有 Edge/Playwright，无新增依赖。

```sh
npm run collect:competitions
node scripts/collect-competitions.mjs --force
```

## 展示规则

- 明确面向在校本科生、大学生或允许所有年级的条件，可判断大一满足年级范围；成绩门槛、专业类别、组队及学校组织条件仍需满足。
- 仅限其他年级的通知不发布，条件不清楚时标为资格待确认。
- 同一来源、同一届赛事在多个链接发布时合并为一条，优先较新的发布版本。
- 过往年度且没有未来报名或比赛日期的栏目文章不发布。英语、三创的当前届次可能已结束：保留历史记录，默认列表及首页不作为未截止机会展示。
- 完整的报名日期范围可自动提取。仅有月份日程不补造具体日期；“某日前”保留原文要求，不当成已核验的校内截止时刻。
- 日期只有年月日时，按中国时区当天结束判断过期，页面仍只显示日期；明确给出时刻时按原时刻判断。
- 全国报名时间不能代替三江校内组织、选拔或报送时间；页面提供报名提示及官方原文入口。
- 不自动报名，不调用 AI，不推断三江学分或积分。抓取失败保留上次数据并报告来源异常。

尚未覆盖所有全国/江苏赛事、其他校内组织渠道、职业规划赛与竞赛聚合平台。现有双创学院通知继续并入同一个“竞赛”分类。下一批可以在本流程增加更多经核验的官方来源。

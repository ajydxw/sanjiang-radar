# 学院与专业目录

核验日期：2026-10-30。专业选择器使用 `src/lib/college-majors.ts` 中的名单和来源。

本目录用于个人资料，不是招生资格或招生计划承诺。优先使用学院当前介绍、专业目录及 2026 年官方新增专业通知；历届专业可能不同，保留“其他 / 未找到我的专业”输入入口。已有手填值不会在升级时被删除；主动切换学院后清空专业，避免跨学院错配。

国际教育学院暂未找到可确认的完整对应专业名单，因此不猜测其专业，提供手动填写。高等职业技术学院的官网专业介绍含本科和专转本且无更新日期，界面明确标注。文学与新闻传播学院介绍中有汉语国际教育，但最新专业目录未单列，界面注明这一差异。艺术学院列出五个招生介绍专业及官网保留的摄影、表演、音乐表演。后者不作为当年招生承诺；摄影和表演另有 2026 教学活动计划佐证。

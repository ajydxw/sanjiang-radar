当前接入方式是**文章链接导入**。已经可以收集、筛选、展示和更新已添加的文章；尚未配置自动发现公众号新推文，不能把单篇导入称为公众号全量订阅。

## 添加与更新

```sh
npm run collect:wechat -- --url https://mp.weixin.qq.com/s/文章编号
npm run collect:wechat
```

链接只接受 `https://mp.weixin.qq.com/s/...` 或其正式文章参数格式。清除登录参数与追踪参数，核验发布者名称为三江学院。文章列表保存在忽略目录 `.sites-runtime/wechat/article-links.json`，浏览器资料和原始网页同样留在忽略目录。

通过本机专用 Edge 阅读公开文章，不安装拦截证书，不改变系统代理。微信返回验证页时停止导入并保留原来的数据；可以在官方页面完成验证后重试。不会把验证页当文章。

公开结果写入 `public/data/wechat.json`，本机 `out/data/wechat.json` 同时更新。页面只展示短摘要和官方原文链接，发布时间必须有页面依据；报名截止与奖励没有明确依据时保持未知。比赛结果、普通宣传等默认不展示。

已添加文章缓存 6 小时，修改后可通过 `--force` 重新核对。默认定时任务每小时检查已添加文章，缓存有效时不重复请求。

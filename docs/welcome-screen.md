# 欢迎页

轻量原创 CSS 雷达扫描与淡入，不引入额外动画依赖。风格研究参考公开项目 [Magic UI](https://github.com/magicuidesign/magicui) 与 [React Bits](https://github.com/DavidHDev/react-bits)，未复制其代码或素材。

- 首页与 #radar 在每次浏览会话首次访问展示；#profile、#saved 等深链接直接访问原页。
- 跳过、直接浏览与 Escape 均可退出。会话内刷新不重复播放；“我的”可主动重新打开。
- Asia/Shanghai 时间，星期与四周循环决定早间文案；晚间固定“月光下的对话”。本地预设，无问候 API、跟踪或新增网络请求。
- 减少动态效果偏好下停用动画；不循环、不强制等待。
- 身份确认暂未开放，不收集姓名或学号。界面仅解释当前状态，游客功能完整。
- verifiedDisplayName 为后续服务端已验证会话预留参数。目前调用方不传值。禁止从自由输入或本地存储伪造已验证身份。登录后的文案只能在同一问候语后追加“，姓名”。

私有后台与名单存储位置需另行确认后再接入。完整名单及手机号等无关字段不可放入公开仓库、静态数据或前端构建产物。

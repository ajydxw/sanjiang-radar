# 本机服务自动启动

在当前 Windows 用户下运行 `scripts/install-private-services-startup.ps1`，注册计划任务 `SanjiangRadar-PrivateServices`。

- 登录 Windows 后后台启动，身份服务使用 4312，小助手使用 4314。
- 计划任务每分钟补查守护进程；正在运行时不会重复启动。
- 守护进程检查本机服务，进程退出后重新启动，不因公网断线重启正在运行的服务。
- 小助手只清理已确认进程不存在的旧锁，不清空账本、不重放请求；异常结束的未结算请求仍按原有规则保留待核对状态。
- 名单、会话和 API 配置仍在 `.sites-runtime/`，不写入启动任务或公共网页。

Tailscale Windows 服务设为自动启动及无人值守；两个 Funnel 使用 `--bg` 保存配置：443 转发至 4312，8443 转发至 4314。网络恢复后由 Tailscale 重连，无需再次登录或手动重新创建入口。不要为了重连删除 Tailscale 登录信息。

由于身份数据使用当前 Windows 用户的 DPAPI 加密，后台服务在该用户登录后启动。电脑关机、休眠或没有网络时公网不能访问；本配置不修改电脑的睡眠、电源或自动登录设置。

维护时先停用并停止计划任务，再处理服务，避免被自动拉起。恢复时启用并启动该任务即可。日志位于 `.sites-runtime/service-watch/`。更换项目目录或 Node 安装路径后，重新运行安装脚本。

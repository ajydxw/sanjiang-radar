# 部署

Node.js 22.18+；npm ci 初始化缺失的空数据，npm run build 生成 out，npm run serve 启动本机完整服务，默认 http://127.0.0.1:4173。通过 RADAR_PREVIEW_PORT 与 RADAR_PREVIEW_HOST 设置端口和监听地址。

仅部署 out 静态目录可使用页面与公开快照，但不会提供共享点赞、问答收件、管理员接口或 /read 文字阅读版。要使用完整功能，需要Node服务及同源HTTPS反向代理。首次管理员设置见 admin.md。

public/data/*.json 是本地生成文件，默认不提交Git；应自行配置数据发布与低频采集。PU登录和浏览器保护当前依赖Windows和Edge。每个采集来源独立失败，不把失败当成没有通知。

自己电脑提供服务时，关机、休眠和断网会影响访问。内网地址只供相同网络访问；跨网访问需自有托管或隧道。仓库不包含维护者的隧道账号、可执行文件和个人电脑快捷方式。

/read 直接读取五份公开快照，每来源显示最近10条未明确排除大一的信息并链接完整JSON，无需浏览器脚本。它不是报名状态保证，所有资格、日期、奖励以官方核对为准。

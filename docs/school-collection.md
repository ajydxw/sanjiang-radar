# 三江学院官网采集第一版

核验日期：2026-10-10。当前先在本机运行，不需要购买服务器、域名或调用 AI。

## 必须收集的考试与办理信息

普通话水平测试、大学英语四六级、全国计算机等级考试是 V1 必须收集的内容。同时关注报名、缴费、准考证打印、培训及考试安排、成绩查询、证书领取，以及选课、补考、重修、转专业、奖助学金等学生办理通知。这些内容进入“学校通知”，不能仅因标题没有“活动”或“竞赛”而降为校园资讯。官网和已导入的公众号文章共用此分类规则。

优先核对学校教务处和语委办的当期通知，再核对学校或学院的官方转载。三江学院[普通话水平测试站介绍](https://www.sju.edu.cn/jwc/pthcszwgkjwcw/list.htm)是职责介绍，不是当期考试通知来源。不能把往年通知中的报名时间、费用、学分或名额用于当前学期，也不能把考试时间当作报名截止。

2026-10-10 发现的覆盖缺口：教务处公开网页读取失败；学校公众号仅导入已提供的文章链接，尚未自动发现新文章；当前 PU 可见活动中未找到普通话通知。这次普通话的报名日期尚未取得可核验的当期原文，不能宣称已同步。班级群和内网通知不在自动采集范围，需补充官方链接或经核实的通知后导入。

## 运行方式

```sh
npm run collect:school
```

默认各栏目最多读取首页 14 条。`-- --limit 5` 缩小本次读取范围；`-- --source sju-innovation` 仅检查双创通知；`-- --force` 重新读取正文。普通运行会复用 6 小时内的正文并检查列表新文章，不做高频请求。

采集结果写到 `public/data/sanjiang-web.json`，已有本机静态预览同时更新 `out/data/sanjiang-web.json`。页面每 5 分钟读取数据文件；本机 `sync:watch` 默认每小时检查官网。电脑和同步进程需要保持运行。

## 省级考试安排补充

2026-10-10 已读取江苏省教育考试院的[四六级信息栏目](https://www.jseea.cn/webfile/certificateexamination_cet/cet_information/)和[计算机等级考试信息栏目](https://www.jseea.cn/webfile/certificateexamination_ncre/ncre_information/)。运行 `npm run collect:exams`，每个栏目检查两个最新办理通知，正文缓存 6 小时，请求间隔至少 500 毫秒。结果写入 `public/data/exams.json` 并同步本机预览；默认定时每小时检查，来源失败保留上次数据。

四六级当期报名已截止；从同一官方原文整理出已报名考生的准考证与考试安排，单独展示，不把准考证打印日期当成补报名截止。计算机等级考试 9 月通知按已截止处理。原文明确的报名时间、考试时间和打印日期分别记录；未公布的成绩查询开通日保持未知，不能将“考后 40 个工作日内”计算成确定日期。仅检查最新两条是当前覆盖限制，不能宣称完整历史。

省级安排不能证明三江学院 2026 级有报考资格，所有省级记录均显示“资格待确认”，须再核对本校通知。国家普通话报名系统的江苏入口需要登录，匿名检查未取得三江本期计划；不从旧年度通知填当前日期。后续取得本校链接或经核实的通知文字再导入。

## 处理流程

```text
公开通知栏目 → 原文网页 → 标题/正文/发布时间/附件
           → 文章 ID 去重 + 内容指纹 → 规则分类
           → 可展示 JSON → 网页卡片 → 官方原文
```

原文网页、每篇解析记录和来源状态保存在 `.sites-runtime/collectors/sanjiang-web/`，不会随源码或静态网站发布。正文发生修改会保存新的指纹版本。同一来源失败时保留上次记录，其余来源照常处理。正文不可读但列表可读时，允许展示列表中有明确依据的标题、发布日期和官方入口；不生成正文、截止、奖励或资格，来源标为部分同步。

比赛、考试与证书办理、报名、课程办理通知和讲座预告优先展示；活动回顾、比赛获奖报道、部分公示、招标和招聘信息留在后台。分类目前是可解释的规则，存在误分可能，需要后续管理员审核。显示的摘要是原文节选，并非 AI 总结。

标题或正文提到日期不等于报名截止。没有明确核验前，不把 `9月21日前` 补成年份和时刻；日期原文作为待审核证据显示。课程加分不等于素质学分，缺少依据不填奖励。年级只有明确的原文证据才判断；学院限制仍待核验。

首页优先展示近 90 天、未明确排除 2026 级的信息，未知资格仍标为待确认；更早的信息在发现页提示核对有效性。`大一可参加` 筛选只保留有明确肯定依据的记录。当前不把任何未核验日期用于主动提醒。

# 三江雷达安全设计

更新：2026-10-12。适用当前 Windows 电脑、网页及问答收件后台和 cpolar 小范围试用部署。

## 已接入的保护

- 使用 [Helmet 8.3.0](https://github.com/helmetjs/helmet) 设置网页安全响应头。静态页面的内联脚本按内容计算 SHA-256 白名单，限制脚本来源；禁止网页被其他站点嵌入，禁止浏览器猜测文件类型，限制引用信息和摄像头、麦克风等权限。本机 HTTP 不强制升级为 HTTPS。
- 静态文件服务仅提供 `out/` 中的普通文件；校验解析后的真实路径，阻止目录越界、隐藏文件和链接文件越界访问。文件接口只接受 GET/HEAD。
- 生活助手仅增加同源问题提交与本人问题读取/删除接口。每题独立随机读取令牌，服务器只存哈希；不提供公开列出所有问题或发布答复的接口。输入、请求体、JSON 类型、来源、容量和频率都有边界，问题存于 Windows 私有运行目录，不加入导出包。
- 问答发布只由站长本机触发，校验指定模型与五项复核记录。访客文字视为数据，不能变成开发指令或执行代码；页面将问题与答复作为纯文本显示，来源只允许 HTTP(S)。这些校验不能替代主助手真的调用模型与复核。
- 手机管理页面使用独立管理员会话；账号不开放注册。密码经随机盐 scrypt 哈希保存，Cookie 为 HttpOnly/SameSite，公网登录只接受 HTTPS，写操作校验同源与 CSRF。管理员才可读全部问题、发布当前已复核草稿和删除记录；普通访客不能调用这些接口。密码重设仅在电脑本机 4398 端口，未放入公网隧道；重设及服务重启使旧登录失效。
- 对全站请求速率、同时处理的请求、连接数和等待时间设上限。只记录汇总事件数量，不记录访问者 IP、网址参数或令牌。cpolar 代理没有经过核验的访客身份，应用不相信客户端传来的转发 IP。
- 公共信息采用明确的字段白名单、链接协议与格式检查、大小限制。采集写入、构建和网页读取使用同一校验；异常内容不发布，网页保留已经成功读取的信息。更新 JSON 使用临时文件与重命名，减少读到不完整文件的机会。
- PU 只调用活动列表、活动详情两个读取接口，核对三江学院学校编号；不导出账号令牌、学号、个人报名或签到状态。密码只在官方登录页面填写。
- cpolar 认证令牌使用 Windows 当前用户的 DPAPI 加密存储；运行中的客户端需要临时明文配置，该目录限定当前用户和 SYSTEM 访问。PU 浏览器资料和本机采集档案同样收紧文件权限，浏览器资料没有整体加密。
- 连接设置页面只监听本机，校验 Host、Origin、随机 CSRF 校验码、内容类型和请求大小，隐藏诊断日志中的认证信息。
- 访客收藏和个人偏好只保存在各自浏览器，网页没有公开的修改信息或管理接口。

## 本机检查与更新

```text
npm run test:security
npm run test:assistant
npm run check:public
npm run audit:security
npm run build
```

启动仍使用桌面「三江雷达启动」按钮。使用同一个 Windows 用户运行采集和连接程序；更换电脑或 Windows 用户时，应重新在官方页面登录并配置连接令牌，不复制明文登录资料。

构建前校验五份公开数据。发布时只复制 `out/`，不复制项目根目录、`.sites-runtime/`、登录资料或采集档案。迁移到其他静态托管时，还需要在新平台配置同等响应头和限流；只上传静态文件不会自动带上本机服务程序的保护。

## 当前边界

校园活动数据仍公开可读，网址不是用户权限控制。正文可能含原通知已经公开的联系人信息；字段白名单不能判断正文中每一句话是否应公开，新增来源仍需检查。

这些措施可以降低误发布凭证、异常脚本、越界读文件和高频请求带来的风险。全站限流超出阈值时会临时拒绝请求，无法替代云端 CDN、WAF 或抗 DDoS，也不能让电脑关机后继续提供服务。浏览器样式需要保留内联样式，脚本没有开放任意内联执行。

Windows DPAPI 限定解密账户，不能防御已经控制当前 Windows 账户或电脑的恶意软件。PU 会话有访问权限保护，仍需锁屏、保持系统与 Edge 更新；异常退出时临时配置可能仍留在受限目录，下一次启动会清理或重建。

参考：[Microsoft DPAPI CurrentUser](https://learn.microsoft.com/en-us/dotnet/api/system.security.cryptography.dataprotectionscope)、[Caddy 可信代理说明](https://caddyserver.com/docs/caddyfile/directives/reverse_proxy#defaults)、[MDN HTTP Observatory](https://github.com/mdn/mdn-http-observatory)。Observatory 用于检查响应头，不是已安装的防火墙。

本次完成的是针对当前架构的加固和功能验证，不等于完整渗透测试、压力测试或独立安全认证。

# PU 活动同步

使用三江学院账号已经登录的官方浏览器会话读取活动，不运行第三方抢报名软件。参考接口经 GitHub 代码和 2026-10-09 的 PU 官方前端核对，已实际读取活动列表与详情。

## 本机运行

需要 Microsoft Edge、Node.js 20.18.1+，以及通过 `npm ci` 安装项目依赖。已登录资料存放在忽略目录 `.sites-runtime/pu/browser-profile/`。同步应由完成登录的同一个 Windows 用户运行。

```sh
npm run collect:pu
npm run sync:watch
```

登录失效时，暂停正在使用该浏览器资料的同步，再运行 `node scripts/login-pu.mjs`；在官方窗口选择三江学院并登录，关闭窗口后恢复同步。密码仅填写在 PU 官方网页，网站不收集密码。

## 同步范围和字段

- 学校编号固定核验为 `235207080935424`，不匹配时停止读取。
- 只调用活动列表和活动详情。按官方默认综合排序（`sort: 0`），每页 50 条、默认最多 20 页；请求间隔至少 750 毫秒。
- `observedTotal`、`pagesRead` 和 `complete` 记录实际返回数量与本次分页范围。达到上限时标为部分同步，不宣称覆盖全校。
- 只从详情的 `baseInfo` 选择活动字段。不导出账号资料、令牌、创建者用户编号、联系方式或该账号的报名/签到状态。
- 报名截止来自 `joinEndTime`，活动结束来自 `endTime`，分别保存；所有结构化时间按北京时间处理。
- 官方年级限制生效时，根据年级名称判断是否包含 2026 级。缺失或无法识别的限制保持未知。
- 网站只展示允许 2026 级或资格未知的信息，明确排除 2026 级的活动不进入公开数据。已截止活动默认隐藏，用户可取消「仅未截止」查看历史记录。
- 结束超过 7 天的活动复用已有详情；未曾读取详情的历史活动只保存到本机列表档案，优先获取仍可行动的信息。
- 2026 级奖励单位结合 PU 官方提示区分积分与学时。志愿活动的 `maxMinutes` 是上限，不能当作实际志愿时长；学时不转换成小时。
- 接口未提供明确发布时间时保留为空，页面显示首次收集时间，不把采集时间当发布时间。
- 容量、已报名人数和剩余名额是同步时快照；报名及最终奖励认定仍前往 PU。

公开结果为 `public/data/pu.json`；本机静态预览的 `out/data/pu.json` 同时更新。完整列表档案及各年级的已核对详情保存在忽略目录 `.sites-runtime/collectors/pu/`，不打包或发布。读取失败保留上次成功数据并更新来源状态，某个详情失败保留其已核对的旧详情。

2026-10-09 实测完成当前账号综合列表的 16 页，共发现 753 条，保留 200 条已核对详情；其中 166 条允许 2026 级或资格未知。这是包含历史记录的数量，不代表 166 条都未截止或都已确认新生可参加，也不代表该账号可见全校所有活动。

## 定时更新

`sync:watch` 默认每 30 分钟检查 PU，每两轮检查官网和已添加的公众号文章链接。运行时网页即使关闭也能采集，但电脑和同步进程必须保持运行；重启后需要重新启动。当前没有云端全天运行服务，也没有手机主动推送。

定时任务更新运行机器上的数据文件。若另外部署了静态快照，需要重新发布或单独配置同步，才会更新远端内容。

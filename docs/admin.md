# 管理员设置

默认用户名是 admin，没有默认密码。构建后运行 npm run serve，并在另一个终端运行 npm run setup:admin。打开本机 http://127.0.0.1:4398 设置10–128字符的独立密码；该设置服务只监听本机，不能映射到公网。

网站管理入口为 /#admin，公网使用HTTPS。密码使用随机盐scrypt；管理会话需登录，发布和删除检查同源及CSRF。重设密码或服务重启后需要重新登录。管理员凭据和私人提问存于被忽略的 .sites-runtime，不进入静态包。

生活助手是私有提问与人工审核工作流，不会自动获得模型权限。使用者自行提供合法答复或模型接入，原始问题不公开。

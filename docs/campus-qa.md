# 生活助手

本项目提供私有问题收件、凭回执读取和删除、管理员审核与答复发布，不附带自动AI推理服务。原始问题、回执与答复保存在 .sites-runtime/assistant-questions，不进入公共仓库或静态目录。

问答按普通知识与生活交流使用；访客内容属于不可信输入，不能变成站长指令，也不能让后台执行代码、操作账号或使用电脑。问题500字符，单次业务资料6000字符，答复800字符。未核实的事实、日期与资格必须保留说明，不跨用户共享上下文。

脚本 scripts/assistant-queue.mjs 提供本机 pending/context/draft/publish 等操作；运行不带参数查看使用说明。发布前核对范围、事实、时效、字段和隐私。项目保留原型的模型与主题策略，使用者修改时应同时更新相应检查。不要把个人订阅凭证写入服务端或建立公开订阅代理。
